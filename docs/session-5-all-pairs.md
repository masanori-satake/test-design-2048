# Session 5: Pairwise法（All-Pairs法）による組み合わせテスト

## 1. 学習目的
* 組み合わせ爆発を起こす多パラメータのテストに対して、Pairwise法（All-Pairs法）を適用してテストケース数を最適化する。
* Pythonライブラリ `allpairspy` と `pytest.mark.parametrize` を活用した効率的なテストコード記述法を学ぶ。

## 2. 現場での悩み
> 「設定項目やパラメータの数が増えると、全組み合わせ（直積）のテスト数が数千件になってしまい実行できません...」
> 「ランダムに選んだ数ケースだけでテストしていて、組み合わせのバグが潜んでいないか不安です...」

## 3. 演習指示
1. **問題設定**:
   * 盤面の状態やスライド方向、タイル設定などの複数要素の組み合わせを検証するシナリオを想定します。
2. **allpairspyの活用**:
   * `allpairspy` を利用して 2 因子間の組み合わせを網羅する効率的なテストデータセットを生成します。
   * **📝 ワークシート関連**: 専用の記入枠はありませんが、**「テスト設計 2: 組合せテスト（デシジョンテーブル / ペア構成法）ワークシート」** の考え方をベースに、因子と水準を整理して取り組みましょう。
3. **テスト実装**:
   * `@pytest.mark.parametrize` を使用して、生成されたペアデータセットを繰り返しテスト実行する構成を作成します。

## 4. 振り返りの問いかけ
* 全組み合わせテスト（直積）と比較して、どれくらいテストケース数を削減できましたか？
* パラメータ化テスト（`parametrize`）を使用することで、テストコードの保守性は向上しましたか？

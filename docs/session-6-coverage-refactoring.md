# Session 6: コード網羅率（カバレッジ）とリファクタリング

## 1. 学習目的
* `pytest-cov` を用いて C1 (Branch Coverage / 分岐網羅) や C0 (Statement Coverage / 命令網羅) を測定・分析する。
* カバレッジ100%の意味と限界（「カバレッジ100%＝バグゼロ」ではないこと）を理解する。
* 充実したユニットテストをセーフティネットにして、安心してコードのリファクタリングを行う体験をする。

## 2. 現場での悩み
> 「カバレッジ100%を目指してテストを書いたのに、本番で障害が発生しました。何が足りなかったのでしょうか？」
> 「リファクタリングしたいけれど、既存のコードを壊してしまうのが怖くて手を付けられません...」

## 3. 演習指示
1. **カバレッジの測定**:
   * 以下のコマンドを実行し、`src/` 配下の各モジュールのカバレッジ率を確認します。
     ```bash
     pytest --cov=src --cov-branch --cov-report=term-missing
     ```
2. **未通過ルートの検出とテスト追加**:
   * レポートで指摘された未通過行（Missing Lines）を確認し、その条件を通るテストを追加します。
3. **リファクタリング**:
   * `board_logic.py` や `game_manager.py` のコード構造を改善（可読性向上、パフォーマンス改善）し、テストが緑（Pass）のままであることを確認します。

## 4. 振り返りの問いかけ
* カバレッジ数値だけに囚われず、「仕様の網羅」ができているかを評価できましたか？
* ユニットテストがあることで、心理的安全性を持ってリファクタリングを実施できましたか？

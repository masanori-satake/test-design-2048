# Session 2: 境界値分析と同値分割

## 1. 学習目的
* 同値分割（Equivalence Partitioning）と境界値分析（Boundary Value Analysis）の技法を習得する。
* 2048の1行スライド・合成ロジック（`slide_and_merge_line`）における境界値や特殊条件（連鎖合成の防止など）を整理する。
* 不具合（バグ）が発生しやすい境界条件を漏れなくテストコードに落とし込む。

## 2. 現場での悩み
> 「テストケースをたくさん書いたのに、境界値（0、最大値、配列の端など）のバグを見逃して本番でエラーになりました...」
> 「どこまでテストすれば十分なのか、基準が分からずテストケースが増えすぎて維持が大変です...」

## 3. 演習指示
1. **仕様の再確認**:
   * `slide_and_merge_line(line)` は長さ4の数値リストを受け取り、左詰めで合成処理を行います。
   * **重要仕様**: 連鎖合成（例: `[2, 2, 2, 2]` が 1回の移動で `[8, 0, 0, 0]` になること）を防ぎ、`[4, 4, 0, 0]` となること。
2. **同値分割と境界値分析**:
   * 有効同値クラス（合成が発生するパターン、合成が発生しないパターン）と無効同値クラスを分類します。
   * 配列内の0の位置（先頭、途中、末尾、すべて0、すべて埋まっている）に応じた境界条件を洗い出します。
3. **テスト実装**:
   * `tests/test_board_logic.py` に `slide_and_merge_line` の境界値テストを追加してください。
